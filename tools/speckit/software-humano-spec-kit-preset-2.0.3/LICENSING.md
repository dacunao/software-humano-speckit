This preset mixes two natures under two licenses. **The boundary is defined by
nature, not by folder.**

manifiesto para el desarrollo de software humano con inteligencia artificial
v2.1**, by Damián Acuña. It is quoted text, not code, and it lives inside the
preset only because that is where Spec Kit resolves it from.
